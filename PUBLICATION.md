# Publication scope

Mohammed AlDamegh confirmed that Syaq is his personal project and authorized publication of the reviewed source excerpt.

Only the source files listed in this repository are included. No old Git objects are imported. The copied modules retain their original comments. The JSON conformance fixture explicitly declares itself synthetic. The added test URLs use example.invalid and invented credentials.

This release deliberately excludes the production application and all data-derived semantic artifacts. The project has unresolved distribution checks for some such artifacts; this source excerpt does not resolve or override them. Do not add datasets, trained models, third-party source, infrastructure exports, notebooks, screenshots, or archives without a separate review.

The included Python tests exercise normalization, the Riyadh release boundary, answer omission, and URL redaction. They do not validate the deployed application or the semantic model.

The published Python modules use only the standard library; the JavaScript code and its tests use the runtime and Node.js built-ins. No external packages, third-party source files, models, datasets, production game schedules, or future answers are bundled. The dated test cases are synthetic boundary checks, not a game schedule. Ownership of the project is not treated as permission to redistribute third-party datasets or derived ranking artifacts.
